# 🥗 NutriAksyon – Child Nutrition Monitoring System

**NutriAksyon** is a full-stack child nutrition monitoring platform designed for schools, teachers, and administrators. It helps track children's nutritional status using automated BMI and Height-for-Age (HFA) computations based on **WHO standards**, provides food recommendations, and generates reports and dashboards for data-driven decision-making.

This repository serves as the **main hub for the NutriAksyon system**, documenting its purpose, features, architecture, and usage while linking to the private frontend and backend repositories.

## 📜 Description

NutriAksyon enables teachers and administrators to monitor child nutrition status efficiently through automated analysis and standardized health metrics.

The system computes **BMI and Height-for-Age (HFA)** automatically, evaluates results using **WHO child growth standards**, and provides actionable insights such as food recommendations and nutrition reports.

### Key Features

- Automated BMI and HFA computation
- Child nutrition analysis based on WHO standards
- Food recommendations according to nutritional status
- Exportable reports per feeding cycle
- Real-time dashboards and analytics
- Secure role-based access control
- Centralized report generation

## 🧑‍💻 Roles & Functionalities

### 👩‍🏫 Teacher

- Secure login using authorized credentials
- Import student class lists
- Manage child profiles
- Record height and weight measurements
- View automated BMI and HFA results
- Identify learners who qualify for the feeding program

### 🧑‍💼 Feeding Coordinator

- Monitor overall nutrition data
- View aggregated reports and dashboards
- Manage feeding cycles
- Oversee teacher submissions
- Review food and nutrition recommendations
- Generate and export reports per feeding cycle

### 🛠️ Administrator

- Manage system users
- Configure system settings
- View system-wide analytics

### 🔐 Super Administrator

- Access authorized system-wide administrative functions
- Manage users and roles
- Perform system maintenance and oversight

## 📊 Reports & Analytics

NutriAksyon provides reporting and analytical features to support school nutrition monitoring and feeding program management.

- Real-time dashboards using charts and statistics
- Exportable reports per feeding cycle
- Data-driven insights for child nutrition monitoring

## 🔒 Privacy & Security

- Child-related and institutional information must be handled in accordance with applicable data protection requirements, including the **Data Privacy Act of 2012 (Republic Act No. 10173)**.
- Access to application source code is restricted to authorized personnel.
- No real user credentials, recovery email addresses, or sensitive personal information should be published in this repository.
- Demonstrations should use synthetic or properly authorized data.
- This project is intended for educational and institutional use.
