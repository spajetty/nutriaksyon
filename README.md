# 🥗 NutriAksyon – Child Nutrition Monitoring System

**NutriAksyon** is a full-stack child nutrition monitoring platform designed for schools, teachers, and administrators. It helps track children’s nutritional status using automated BMI and HFA computations based on **WHO standards**, provides food recommendations, and generates real-time reports and dashboards for data-driven decision-making.

This repository serves as the **main hub** for the NutriAksyon system. It documents the system’s purpose, features, architecture, and usage while linking to the private frontend and backend repositories.

## 📜 Description

NutriAksyon enables teachers and administrators to monitor child nutrition status efficiently through automated analysis and standardized health metrics.

The system computes **BMI and Height-for-Age (HFA)** automatically, evaluates results using **WHO child growth standards**, and provides actionable insights such as food recommendations and nutrition reports.

Key Features:
- Automated BMI & HFA computation
- Child nutrition analysis based on WHO standards
- Food recommendations per nutritional status
- Exportable reports per feeding cycle
- Real-time dashboards and analytics
- Secure role-based access
- Centralized report generation

## 🧑‍💻 Roles & Functionalities

### 👩‍🏫 Teacher
- Secure login via credentials
- Import student classlist
- Manage child profiles
- Record height and weight data
- View automated BMI & HFA results

### 🧑‍💼 Coordinator
- Monitor overall nutrition data
- View aggregated reports and dashboards
- Manage feeding cycles
- Oversee teacher submissions
- Receive food and nutrition recommendations
- Generate and export reports per cycle

### 🛠 Admin
- Manage system users
- Configure system settings
- View system-wide analytics

### 🔐 Super Admin
- Full system access
- User and role management
- System maintenance and oversight
